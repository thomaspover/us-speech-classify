# Congressional communication explorer

Interactive comparisons of congressional speeches, tweets and campaign websites, by party.

[Open the dashboard](https://thomaspover.github.io/us-speech-classify/) after GitHub Pages deploys. Alternatively, download `index.html` and open it in your browser.

This repository contains the requested self-contained HTML and hosting configuration. Supporting report downloads remain in the local research workspace. The graphs retain the existing design, embedded data and research caveats. Stance results remain exploratory and have no independent human validation.
